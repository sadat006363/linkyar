# GoVoiceLink - Voice-Powered Link Assistant

The fastest way to manage and share your social links with voice commands.

## Features

- 🔗 Manage all your social links in one place
- 🎤 Voice commands to copy links instantly
- ☁️ Cloud storage with Supabase
- 📱 Mobile-first responsive design
- 🔒 No sign-up required

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Shadcn/ui
- Supabase
- Vercel

## Getting Started

```bash
npm install
npm run dev
